# 🍈 Durian Hub — ตลาดกลางทุเรียนไทย

ระบบตลาดกลางซื้อ-ขาย-รับตัดทุเรียนไทย พร้อมแดชบอร์ดราคารายพื้นที่ ระบบสมัครสมาชิก/ยืนยัน OTP และห้องแชทเจรจาตกลงราคาแบบสด (Real-time)

📖 **[คู่มือคำสั่ง Windows CMD ฉบับเต็ม](docs/cmd-guide.md)** — รัน Docker/Node.js, จัดการฐานข้อมูล, ทดสอบ, สำรองข้อมูล และแก้ปัญหาที่พบบ่อย

🗃️ **[MySQL schema ล่าสุดและไฟล์สำหรับวาด ER Diagram](database/README.md)** — SQL และ DBML ที่สร้างจาก Prisma ปัจจุบัน

## 🚀 วิธีรันโปรเจกต์ด้วย Docker (สำหรับส่งให้เพื่อนหรือเครื่องอื่น)

เครื่องปลายทางต้องมีแค่ **Docker Desktop** เพียงอย่างเดียว (ไม่ต้องติดตั้ง Node.js หรือ MySQL ใดๆ ในเครื่อง)

### ขั้นตอน:
1. แตกไฟล์ Zip โปรเจกต์ หรือ Clone มาไว้ที่เครื่อง
2. เปิดโปรแกรม **Docker Desktop**
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่งเดียว:
   ```bash
   docker compose up --build -d
   ```
4. รอระบบ Build และสตาร์ททุก Service อัตโนมัติ (ระบบจะรอ MySQL พร้อม -> ดัน Schema -> Seed ข้อมูลเริ่มต้นให้เอง)
5. เปิดเบราว์เซอร์เข้าใช้งานได้ทันที:
   - 🌐 **เว็บแอปพลิเคชันตลาดกลางทุเรียน:** [http://localhost:3000](http://localhost:3000)
   - 📧 **กล่องดูอีเมลทดสอบ OTP (Mailpit):** [http://localhost:8025](http://localhost:8025)

## ส่ง OTP ผ่าน Gmail หรือกลับมาทดสอบด้วย Mailpit

เลือกโหมดใน `.env` ที่โฟลเดอร์โปรเจกต์ แล้วกด **เริ่มระบบเว็บ** ใน Launcher เพื่อใช้ค่าที่แก้

| โหมด | ค่าใน `.env` | วิธีตรวจ OTP |
| --- | --- | --- |
| Gmail | `COMPOSE_FILE=docker-compose.yml;docker-compose.gmail.yml` | ตรวจกล่องจดหมายหรือสแปมของอีเมลที่ใช้สมัคร |
| Mailpit | `COMPOSE_FILE=docker-compose.yml` | เปิด http://localhost:8025 |

เก็บ `COMPOSE_PATH_SEPARATOR=;` ไว้ทั้งสองโหมด สำหรับ Gmail ให้เปิดการยืนยันแบบ 2 ขั้นตอน สร้าง App Password ของบัญชีผู้ส่ง ใส่อีเมลใน `GMAIL_USER` และใส่รหัสแอปโดยตัดช่องว่างใน `GMAIL_APP_PASSWORD` ภายในไฟล์ `.env` ของเครื่อง [วิธีสร้าง App Password ของ Google](https://support.google.com/accounts/answer/185833)

หากใช้ Terminal ให้รัน `docker compose up -d web` หลังแก้ค่า เมื่อเปลี่ยนจาก Mailpit เป็น Gmail ให้รัน `docker compose --profile mailpit stop mailpit` เพื่อปิดกล่องทดสอบเดิม Launcher ทำขั้นตอนนี้ให้เมื่อกดเริ่มระบบเว็บ

## ความเป็นส่วนตัวของแชตและคำร้อง

ให้บริการสาธารณะผ่าน HTTPS ข้อความและรูปแชตอ่านได้จากบัญชีคู่สนทนา ผู้ดูแลที่รับคำร้องสามารถเปิดหลักฐานของห้องที่เกี่ยวข้องได้ขณะดำเนินการ โดยระบบเก็บรหัสผู้ดูแล รหัสคำร้อง และเวลาเปิดดู รูปแชตใช้ URL ที่ตรวจสิทธิ์ก่อนส่งไฟล์

ห้องที่ปิดแล้วส่งข้อความได้อีก 7 วันและเปิดอ่านประวัติได้หลังจากนั้น การตั้งค่านี้เป็นระยะเวลาส่งข้อความ ระบบยังเก็บประวัติกับไฟล์เพื่อใช้กับคำร้อง ผู้ดูแลระบบต้องกำหนดระยะเวลาจัดเก็บและขั้นตอนลบตามนโยบายก่อนประกาศวันลบให้ผู้ใช้ทราบ

## 🛠️ คำสั่งเพิ่มเติมสำหรับจัดการ Docker

- **ดู Log การทำงานของเว็บ:**
  ```bash
  docker compose logs -f web
  ```
- **หยุดการทำงาน:**
  ```bash
  docker compose down
  ```
- **หยุดและลบข้อมูลใน Database ทั้งหมดเพื่อเริ่มใหม่:**
  ```bash
  docker compose down -v
  ```
