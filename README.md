# 🍈 Durian Hub — ตลาดกลางทุเรียนไทย

ระบบตลาดกลางซื้อ-ขาย-รับตัดทุเรียนไทย พร้อมแดชบอร์ดราคารายพื้นที่ ระบบสมัครสมาชิก/ยืนยัน OTP และห้องแชทเจรจาตกลงราคาแบบสด (Real-time)

📖 **[คู่มือคำสั่ง Windows CMD ฉบับเต็ม](docs/cmd-guide.md)** — รัน Docker/Node.js, จัดการฐานข้อมูล, ทดสอบ, สำรองข้อมูล และแก้ปัญหาที่พบบ่อย

🗃️ **[MySQL schema ล่าสุดและไฟล์สำหรับวาด ER Diagram](database/README.md)** — SQL และ DBML ที่สร้างจาก Prisma ปัจจุบัน

## 🚀 วิธีรันโปรเจกต์ด้วย Docker (สำหรับส่งให้เพื่อนหรือเครื่องอื่น)

เครื่องปลายทางต้องมีแค่ **Docker Desktop** เพียงอย่างเดียว (ไม่ต้องติดตั้ง Node.js หรือ MySQL ใดๆ ในเครื่อง)

### ขั้นตอน:
1. แตกไฟล์ Zip โปรเจกต์ หรือ Clone มาไว้ที่เครื่อง
2. เปิดโปรแกรม **Docker Desktop**
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่งเดียว:
   ```bash
   docker compose up --build -d
   ```
4. รอระบบ Build และสตาร์ททุก Service อัตโนมัติ (ระบบจะรอ MySQL พร้อม -> ดัน Schema -> Seed ข้อมูลเริ่มต้นให้เอง)
5. เปิดเบราว์เซอร์เข้าใช้งานได้ทันที:
   - 🌐 **เว็บแอปพลิเคชันตลาดกลางทุเรียน:** [http://localhost:3000](http://localhost:3000)
   - 📧 **กล่องดูอีเมลทดสอบ OTP (Mailpit):** [http://localhost:8025](http://localhost:8025)

## 🛠️ คำสั่งเพิ่มเติมสำหรับจัดการ Docker

- **ดู Log การทำงานของเว็บ:**
  ```bash
  docker compose logs -f web
  ```
- **หยุดการทำงาน:**
  ```bash
  docker compose down
  ```
- **หยุดและลบข้อมูลใน Database ทั้งหมดเพื่อเริ่มใหม่:**
  ```bash
  docker compose down -v
  ```
