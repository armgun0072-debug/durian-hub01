# Durian Hub — ภาพ Flowchart ภาษาไทย

เปิด [index.html](index.html) เพื่อดูทั้ง 10 ภาพ หรือเลือกไฟล์ PNG / SVG จาก [เอกสารหลัก](../project-flowchart.md)

- PNG: ภาพกว้าง 1,400 พิกเซล เหมาะสำหรับใส่รายงานและสไลด์
- SVG: ภาพเวกเตอร์พร้อมข้อความไทย ซูมได้โดยภาพไม่แตก ใช้ฟอนต์ Tahoma หรือฟอนต์ไทยสำรองในเครื่อง
- [generate.ps1](generate.ps1): ต้นฉบับที่แก้ข้อความ ตำแหน่ง และเส้นเชื่อมได้ สร้างทั้งสองรูปแบบจากข้อมูลเดียวกัน โดยไม่ติดตั้งแพ็กเกจเพิ่ม
- [validation.json](validation.json): จำนวนโหนด เส้นเชื่อม ขนาดภาพ และผลตรวจ XML ของ SVG แต่ละภาพ

สีเขียวเข้มคือเริ่มต้น สีเขียวอ่อนคือผลลัพธ์/สำเร็จ รูปข้าวหลามตัดสีเหลืองคือเงื่อนไข สีฟ้าคือข้อมูล และสีแดงคือข้อผิดพลาดหรือคำขอที่ไม่ผ่าน เส้นทางที่จบด้วยข้อความให้ลองใหม่หรือกลับไปล็อกอินเป็นจุดส่งต่อ ไม่จำเป็นต้องวาดลูกศรย้อนทุกเส้น

สร้างซ้ำบน Windows PowerShell จาก root โปรเจกต์ (อ่าน UTF-8 อย่างชัดเจนเพื่อให้ภาษาไทยถูกต้อง):

```powershell
& ([scriptblock]::Create((Get-Content -LiteralPath docs/flowcharts/generate.ps1 -Raw -Encoding UTF8))) -OutputDirectory (Join-Path (Get-Location) 'docs/flowcharts')
```

สคริปต์ใช้ System.Drawing ซึ่งต้องรันบน Windows และจะเขียนทับไฟล์ภาพ หน้ารวม และ validation ในโฟลเดอร์ผลลัพธ์ ไม่อ่านหรือแก้ฐานข้อมูล

ข้อมูลอ้างอิงจากโค้ดที่ตรวจเมื่อ 2 พฤศจิกายน 2569 โดยแต่ละภาพระบุไฟล์หลักที่เกี่ยวข้อง ภาพไม่ใช่ผลทดสอบระบบครบวงจร ข้อตกลง ACCEPTED ไม่ได้ยืนยันชำระเงินหรือจัดส่ง และสถิติราคาบางส่วนเป็นค่าตั้งต้น/ค่าประมาณตามพฤติกรรมหน้าเว็บปัจจุบัน
