# ผลปรับปรุง UX/UI ผู้ใช้และแอดมิน — 2026-11-11

ผู้ใช้อนุมัติแผนจาก [รายงานตรวจ](ux-ui-audit-2026-11-11.md) ด้วยคำว่า “ลุยปรับทั้งผู้ใช้และแอดมิน”

## สิ่งที่เปลี่ยน

### ฝั่งผู้ใช้

- เมนูมือถือแบ่งสี่ช่อง ไม่ตัดหมวดข้อความที่ความกว้าง 320px; ตัวกรองสายพันธุ์ใช้ dropdown บนมือถือ ลดแถบเลื่อนแนวนอน
- แชทจัดปุ่มงานเป็นสองคอลัมน์บนมือถือ เพิ่มขนาดพื้นที่กดและชื่อปุ่มส่งข้อความ ปุ่มส่งปิดเมื่อข้อความว่าง; quick reply เติมร่างให้ตรวจสอบก่อนส่ง
- ประกาศมีสถานะกำลังโหลด/ผิดพลาดพร้อมลองใหม่/ไม่มีข้อมูล แยกจากกัน เลือกช่วง 7 วัน, 30 วัน หรือทั้งหมดได้ และป้องกันผล request เก่าเขียนทับตัวกรองล่าสุด
- แสดง “ยังไม่มีรีวิว” เมื่อจำนวนรีวิวเป็นศูนย์ แทนคะแนน 5.0 ใช้รูปแบบเดียวกันในหน้าหลัก การ์ด รายละเอียด โปรไฟล์และการตั้งค่าบัญชี
- หน้าราคาอธิบายแหล่งข้อมูล ช่วงเวลา และเวลาโหลด ระบุค่าตัวอย่างเมื่อไม่มีประกาศ และแจ้งว่าเป็นราคาเสนอ ไม่ใช่ราคาซื้อขายสำเร็จ
- การ์ดรองรับรูปประกาศจริงพร้อม fallback เมื่อรูปโหลดไม่ได้; เพิ่มความชัดเจนของ placeholder และขนาดปุ่มธีม แก้ข้อความเครือข่ายตามภาษาและ document lang

### ฝั่งแอดมิน

- ตารางเปลี่ยนเป็นการ์ดพร้อมชื่อฟิลด์บนจอแคบกว่า 1024px; จอใหญ่คงตารางสำหรับเปรียบเทียบข้อมูล
- เพิ่มตัวเลือกเข้าถึงทั้งห้าหมวดบนมือถือ ช่องค้นหามีปุ่มล้างและข้อความเมื่อไม่พบผลลัพธ์
- เครือข่าย/เซิร์ฟเวอร์ผิดพลาดแสดงคำเตือนและปุ่มลองใหม่ เก็บข้อมูลล่าสุดและสถานะเข้าสู่ระบบ; แยกจาก HTTP 401/403
- แทน browser alert/confirm ด้วยกล่องยืนยันในแอป ระบุรายการและผลของคำสั่ง ยกเลิกด้วย Escape ได้ เพิ่มสถานะทำงานและป้องกันคำขอซ้ำระหว่างรอ response
- ไม่สมมติจังหวัดเมื่อไม่มีข้อมูล และเอาคำกล่าวอ้าง “256-bit”/“Real-time” ที่ไม่มีหลักฐานออก

## หลักฐานการตรวจ

| การตรวจ | ผล |
| --- | --- |
| TypeScript `--noEmit --incremental false` | ผ่าน |
| UI feedback / theme / market-stats | ผ่าน 13/13 |
| ชุดทดสอบรวม | ผ่าน 139/146; ไม่ผ่านเดิม 7 ข้อใน `tests/post-roles.test.cjs` |
| Static demo `npm.cmd run build:pages` | ผ่าน compile/type check/export หลังแก้ไข |
| Browser จริง | Edge native + device emulation; ไม่ใช่มือถือจริง |

ตรวจหลังแก้ไข: หน้าหลัก/เมนูที่ 320px light และ dark, marketplace 390px และเปลี่ยนช่วง 30 วันพบข้อมูล 6 ประกาศรวมทุกประเภท, แชท 390px dark และ 320px light, แอดมิน 390px light/dark และ 768px/1440px dark, เพิ่มตรวจภาพรวมแอดมิน 320px dark

ทดสอบค้นหาแอดมินแล้วไม่พบผลลัพธ์และล้างคำค้นได้ เปิดกล่องยืนยันลดคะแนนแล้วกด Escape คะแนนยังเดิม ไม่ส่งคำสั่งลงโทษ ทดสอบ Offline แล้วกดรีเฟรช: แสดงข้อมูลเดิมและคำเตือนโดยไม่ออกจากระบบ เมื่อคืน No throttling แล้วลองใหม่ คำเตือนหายและข้อมูลยังแสดง คืน browser เป็น online และปิด DevTools แล้ว

## ขอบเขตและข้อจำกัด

- ซิงก์ source เข้า Docker local ที่ให้บริการ localhost:3000 แล้ว ยังไม่ได้เผยแพร่สู่ระบบสาธารณะ
- ไม่เปลี่ยน API, schema, authentication service หรือข้อมูลธุรกรรม ข้อผิดพลาด role tests เดิมยังต้องแก้แยกงาน
- ยังไม่ได้รับรอง WCAG, screen reader, มือถือจริง หรือทุกหน้าทุกขนาดในทุกธีม; ไม่ทดสอบส่งข้อความ/ซื้อขาย/ลงโทษสมาชิกจริง
- Impeccable engine ไม่พร้อมใช้งานในสภาพแวดล้อมนี้ ใช้แนวทางจาก Skill ตรวจโค้ดและหน้าจอด้วยตนเอง
